Installer l'application

Sur iPhone/iPad, l'installation se fait via Safari :

  1. Ouvrez ce site dans Safari (pas Chrome)
  2. Appuyez sur l'icône Partager (le carré avec la flèche vers le haut)
  3. Choisissez "Sur l'écran d'accueil"
  4. Appuyez sur Ajouter

Installer l'application

Votre navigateur n'a pas proposé l'installation automatique. Vous pouvez le faire manuellement :

  1. Ouvrez le menu du navigateur (généralement les trois points ⋮ en haut à droite)
  2. Choisissez "Installer l'application" ou "Ajouter à l'écran d'accueil"
  3. Confirmez

Sur ordinateur (Chrome/Edge), l'icône d'installation apparaît aussi parfois directement dans la barre d'adresse, tout à droite.
